현재 변경사항을 코드 리뷰 에이전트와 테스트 에이전트로 병렬 검증해.

## 실행 순서

1. 아래 두 에이전트를 **동시에** 실행
2. 양쪽 결과를 취합
3. 블로커(즉시 수정 필요) / 경고(권장 수정) / 통과 로 분류해서 최종 보고

## 에이전트 1 — 코드 리뷰

다음 항목을 검토:
- 타입 안전성 (`any` 사용, 타입 단언 남용, 누락된 반환 타입)
- 버그 가능성 (엣지 케이스, null/undefined 처리, 비동기 오류 처리)
- 보안 취약점 (XSS, 환경변수 노출, 인증 누락)
- CLAUDE.md 컨벤션 위반 (FSD 레이어 규칙, 네이밍, import 방향)
- 불필요한 렌더링 / 성능 안티패턴

## 에이전트 2 — 테스트 검증

다음 항목을 검토:
- 변경된 로직에 대한 테스트 존재 여부
- 테스트가 없으면 핵심 케이스 작성 (happy path + edge case)
- 기존 테스트 실행 후 결과 보고 (`pnpm test` 또는 해당 커맨드)
- 커버리지가 부족한 영역 명시
