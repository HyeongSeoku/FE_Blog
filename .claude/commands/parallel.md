$ARGUMENTS 작업을 독립적인 단위로 쪼개 병렬 subagent로 처리해.

## 순서

1. 작업을 독립적인 단위로 분해
2. 각 단위를 별도 subagent에 위임해 병렬 실행
3. 결과 취합 후 충돌 여부 확인
4. 최종 결과 보고

## 병렬 처리 기준

- 파일 간 의존성이 없는 경우 → 병렬 처리
- 같은 파일을 수정하는 경우 → 순차 처리
- 탐색과 구현이 섞인 경우 → Explore 먼저, 구현은 그 다음

## 사용 예시

```
/parallel 로그인, 회원가입, 비밀번호 찾기 페이지 UI 수정
/parallel 버튼, 인풋, 모달 컴포넌트 접근성 개선
```
