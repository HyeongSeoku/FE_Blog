현재 작업 상태를 다음 세션이나 다른 에이전트가 이어받을 수 있도록 핸드오프 문서를 작성해.

## 목적

컨텍스트가 리셋되어도 작업을 끊김 없이 이어갈 수 있게 한다.

## 핸드오프 문서 내용

### 현재 상태 요약
- 달성한 것
- 현재 작업 중인 것
- 아직 하지 않은 것

### 핵심 결정 사항
이번 세션에서 내린 중요한 기술적 결정들:
- 무엇을 선택했는가
- 왜 선택했는가
- 고려했지만 선택하지 않은 대안

### 발견된 컨텍스트
코드베이스 탐색으로 파악한 중요 사항:
- 관련 파일 위치
- 주의해야 할 패턴
- 예상치 못한 의존성

### 다음 단계
구체적으로 해야 할 작업:
- [ ] {작업 1} — `{관련 파일}`
- [ ] {작업 2} — `{관련 파일}`

### 열린 질문
아직 해결되지 않은 것들:
- {질문 1}
- {질문 2}

### 주의사항
이어받는 에이전트/사람이 알아야 할 함정이나 위험 요소.
